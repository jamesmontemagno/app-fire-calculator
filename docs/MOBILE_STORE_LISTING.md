## Description

My Fire # helps you explore financial-independence scenarios with 11 focused
calculators, including Standard, Coast, Lean, Fat, Barista, Reverse, debt payoff,
healthcare gap, savings rate, withdrawal rate, and retirement cash flow.

Build and compare named plans, adjust common assumptions, visualize projections,
and export accessible Excel workbooks. Calculations are estimates for educational
purposes and are not financial advice.

Financial inputs, drafts, plans, and quiz answers stay in local app storage. The
app has no accounts, analytics, advertising, or automatic data upload. The
operating system may include app data in an encrypted device backup when the user
enables platform backups. Backup export and legal links run only after an explicit
user action.

## Review Notes

The app is fully usable without an account or network connection. On first launch,
reviewers may complete or skip the FIRE Quiz. All calculators are available from
the Calculators tab. Settings contains theme, accessibility, calculator defaults,
currency, local backup/restore, legal links, and confirmed data deletion.
